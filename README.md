# 📊 Poonawalla Fincorp FP&A Transformation Model

## Executive Summary

This project demonstrates a CFO-level FP&A model developed using publicly available financial information and strategic assumptions.

The objective was to simulate how an FP&A team can support senior management in:

- Annual Operating Plan (AOP)
- Budgeting
- Rolling Forecast
- Business Performance Review
- Executive Decision Making
- Capital Planning
- Cost Optimization
- Strategic Growth
